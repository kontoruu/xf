## 🎯 Apa yang script ini lakukan? / What does this script do?

### Singkat / Short Version:
Script ini menganalisis pasar kripto Indodax dan memberikan sinyal trading otomatis berdasarkan indikator teknikal.

This script analyzes Indodax crypto market and provides automated trading signals based on technical indicators.

### Detail / Detailed:
- ✅ Real-time data dari Indodax API / Real-time data from Indodax API
- ✅ 10 timeframe analisis (15m - 1 bulan) / 10 timeframe analysis (15m - 1 month)
- ✅ 5 indikator teknikal (RSI, StochRSI, BB, Volume, Momentum) / 5 technical indicators
- ✅ Scoring system 0-100
- ✅ Rekomendasi BUY/SELL otomatis / Automated BUY/SELL recommendations
- ✅ UI bergaya stock exchange / Stock exchange style UI
- ✅ Auto-refresh real-time
